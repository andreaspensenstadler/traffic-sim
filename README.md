# traffic-sim

2D-Verkehrssimulation (Top-Down) mit Godot 4 – Lernprojekt Spieleentwicklung.

## Voraussetzungen

- Godot 4.x (lokal installiert unter `~/.local/bin/godot`)

## Projekt öffnen

```sh
godot --editor project.godot
```

## Struktur

- `scenes/` – Godot-Szenen (`.tscn`)
- `scripts/` – GDScript-Dateien
- `assets/` – Grafiken, Sounds etc.
